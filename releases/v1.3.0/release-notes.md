# Tabatha 1.3.0

_First public release (Chrome Web Store submission)._

- Live tab previews: a screenshot of each tab, captured when the tab is shown
- Alt+Q / Alt+Shift+Q hold-and-release switching in most-recently-used order
- Search across open and recently closed tabs
- Window filter chips (Alt+W) when more than one window is open
- Recently closed tabs and windows, with previews kept for 30 minutes
- Close tabs from the switcher (Del / middle-click)
- Popup-window fallback on pages extensions can't draw on
- Hardened overlay: one-time launch token, clickjacking guard, strict CSP with no network access
